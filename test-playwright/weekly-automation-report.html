02Merchandise Automation — perbaikan false-fail

Bug fix

functional.checkout.spec.js & functional.orders.spec.js gagal di setiap run

merchandise/automation — merchandise-dev.modena.com
Fixed

Sejak /login berubah jadi Microsoft-SSO-only (3 Agustus), fungsi login() di fixtures.js sengaja dibuat langsung throw agar caller lama gagal jelas. Dua spec — checkout dan orders — masih memanggil login() ini secara aktif, jadi tiap run pasti error, bukan cuma "belum bisa jalan".

  • Kedua file diubah ke test.describe.skip(...) dengan alasan tercatat di kode: tidak ada akun test SSO atau auth-bypass route di dev environment ini.
  • 9 test lain yang sudah di-skip sebelumnya (functional.auth.spec.js, smoke.spec.js, functional.pdp_cart.spec.js) dikonfirmasi tetap sesuai — cakupan login, cart, dan order-history memang belum ada sampai ada akun test SSO.

03MHC Staging (Sync SAP) — rewrite penuh, terverifikasi live

Major finding

12 menu "CRUD" ternyata read-only sync viewer

more1/mhc/staging/staging — more-dev.modena.com
60/60 passing

Login langsung ke environment dev dan inspect DOM tiap menu (Bank, Warehouse, BP Group, PPh) menunjukkan: 12 file spec "CRUD" (Bank, BP, BP Address, BP Branch, BP Group, GL Account, Legal, Order Type, PPh, PPN, Series, Warehouse) menguji fitur yang tidak pernah ada. Halaman "Sinkronisasi SAP" hanya punya List, Search, Filter builder AND/OR, Sort, dan tombol "Sinkronkan Semua" — tanpa Add/Edit/Delete di manapun.

  • Ditemukan juga 2 bug independen: URL list kurang prefix /mhc/ (/sync-sap/bank/list → seharusnya /mhc/sync-sap/bank/list), dan selector login pakai input[type="email"] yang sudah tidak ada di DOM (form pakai placeholder + dropdown Company wajib).
  • Seluruh 12 spec ditulis ulang memakai helper bersama fixtures.js#registerStagingSuite() — 5 test per menu: List, No-Manual-CRUD (guard regresi kalau Add/Edit/Delete suatu saat benar-benar ditambahkan), Search, Filter, Sync.
  • Dijalankan live berulang sampai stabil: 60 dari 60 test lulus di seluruh 12 menu.
  • Template lama (templates/crud-template.spec.js dan template-crud.spec.js yang kosong) diperbarui agar tim tidak menduplikasi asumsi CRUD yang salah di menu staging berikutnya.
